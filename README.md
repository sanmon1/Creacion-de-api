Buscador de Personajes — Rick and Morty

Buscador de personajes de la serie Rick and Morty, que consume la API pública de Rick and Morty para mostrar información de personajes: nombre, estado (vivo/muerto/desconocido), especie, género, ubicación y episodios en los que aparece.
-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

Características

Busqueda de personajes por nombre y en tiempo real
Boton de personaje Aleatorio
